# Проект-задание по сокращению URL-адреса

### Для его локального запуска рекомендуется использовать docker-compose - внутри связи уже настроены

> (если его нет, но есть строки для подключения к уже развёрнутому - идём в файл appsettings.Development.json в корне приложения и корректируем строку подключения).

### Я предпочитаю запускать проект прямо из среды разработки, поэтому уточню для такого же запуска и запуска командой в консоли (при наличии установленного docker-desktop):

## 1. Прямо из **Visual studio** (работает в **2022** и **2026** версиях при наличии подходящих компонентов):

в верхней части окна разработки, перед запуском, мы выбираем docker-compose (иногда для этого нужно в "обозревателе решений" переключиться на сам docker-compose проект/блок)


## 2. Из консоли (терминала):

Переходим в каталог с проектом (тот, где находятся файлы docker-compose.yml), зажимаем Shift и правой кнопной мыши на пустое место - "Открыть в терминале" (или открыть PowerShell тут).
Далее - вводим команду:
`docker compose -f .\docker-compose.yml up -d --build --force-recreate`
